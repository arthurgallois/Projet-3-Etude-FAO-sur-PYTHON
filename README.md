# Projet-3-Etude-FAO-sur-PYTHON
Etude de l'état de l'alimentation dans le monde
A partir des données sur la disponibilité alimentaire mondiale, une étude sur les inégalités sur l'accès à la nourriture a été réalisée sur Python, via l'interface JupyterLab.

Le projet est une simple application des bibliothèques Pandas, Numpy et MatPlotLib, mais son importance est capitale.
